# GitHub Desktop 管理

本仓库通过GitHub Desktop添加、首次提交并发布。建议远程仓库名为`ielts-speaking-simulator-live`；默认使用私人可见性。发布结果以客户端显示的实际仓库链接为准。

后续修改后，在GitHub Desktop的Changes中检查文件，填写提交说明并Commit，再Push origin。不要把本地`.git/`目录通过GitHub网页当作普通文件上传。

简介可复制根目录`DESCRIPTION.txt`，英文版见`GITHUB_DESCRIPTION.en.txt`。第三方资料范围见根目录`LICENSE_SCOPE.md`与`THIRD_PARTY_NOTICES.md`。
