# IELTS SPEAKING SIMULATOR LIVE — portable edition

Download [the Markdown with YAML](IELTS-SPEAKING-SIMULATOR-LIVE-PORTABLE.md) and attach it directly in a supported mobile or desktop model client, or add it to an assistant's knowledge configuration. Ask the model to follow its runtime rules. The file embeds full rules, descriptors, tests and corpus.

For step-by-step mobile import and ChatGPT plugin installation, see the [Chinese guide](../docs/INSTALLATION.zh-CN.md) or [English README](../README.md).
